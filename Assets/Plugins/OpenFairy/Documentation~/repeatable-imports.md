# Repeated resource imports

The importer compares generated bytes with the existing file before writing.
Image settings, sprite borders and existing platform size overrides are only
saved when they differ. Tiled images retain transparent-edge trimming; movie
frames retain their authored canvas dimensions. Font atlas images and sounds
use the same byte comparison, while unchanged bitmap-font glyph data is not
marked dirty. Existing asset metadata and GUIDs are preserved.

A new texture may still need an initial import to create its importer, followed
by one import with its final settings. Repeating the same resource input and
settings should produce no further image or sound imports. This does not skip
prefab generation or claim that a complete migration performs no asset work.

Editor tests observe native import callbacks, preserve GUIDs and verify tiled
cropping, nine-slice borders, audio and bitmap fonts after clearing transient
lookup caches. They require Unity; offline compilation does not execute them.
