# Native TMP text shadows

The TMP importer converts authored `shadowColor` and `shadowOffset` into a persistent native SDF material preset. The text stores a direct `fontSharedMaterial` reference. `TextShadow` remains the mesh effect for the built-in uGUI text backend; TMP does not execute that mesh modifier. No shadow text object, custom renderer, runtime material cache or per-frame mesh copy is added.

The preset copies its font material and enables the official SDF underlay keyword. Offset conversion uses the authored font size, face size/scale, gradient scale and native scale ratio. Positive authored Y goes down, so the shader Y offset is negated. Font assets and their shared materials are not changed. Ordinary TMP material-preset matching supplies a fallback font's atlas, and native TMP owns and releases its fallback material instances. The regular source preset is an asset, not an unmanaged runtime allocation.

This follows native SDF limits: available atlas padding bounds the offset, and changing or autosizing the font scales the preset's effect with the glyphs. It is not an arbitrary-size pixel-identical copy of the original mesh offset. This path requires a native SDF material with underlay properties; it does not emulate shadows for bitmap shaders or inline sprites. Fallback styling follows TMP's material-preset matching setting. Inherited CanvasGroup alpha and text alpha both affect the shadow.

`Migrate.RefreshTextShadows()` is a narrow Editor operation for already-published bindings. It reads the same source package/component metadata, prepares and saves the material assets first, then reopens the persistent prefab assets and updates only the bound text materials. It does not rebuild hierarchy, generate scripts, run localization or project postprocess hooks, or call the full migration. Generated public fields keep the first authored name and are checked against the published object. Repeated or unpublished text names are resolved only in the Editor, using the source group/mask hierarchy and ordered same-name siblings. Input fields use their direct textComponent reference. Missing public bindings or mismatched hierarchy are reported instead of silently skipped; regenerate stale bindings before this operation. No runtime name lookup or new binding component is added. Existing components without shadows are left alone. The method returns the number of refreshed authored text entries and logs the component count. It does not remove assets for deleted source entries.

Native tests preserve GUID/local file IDs, group parenting, nested-prefab inheritance and the parent's serialized bytes. A repeated refresh keeps the material count and prefab bytes unchanged. GPU tests cover white glyphs on white background, text/parent alpha, disable/enable, fallback atlas/material release and PMA capture of SDF underlay. The original missing-shadow failures remain separate receipts. At the feature introduction, the full package checkpoint passed 127 Editor and 170 PlayMode tests in the TMP Editor/Mono host; Builtin had separate compilation coverage. The latest same-version package totals are maintained in the SDK AGENTS.md and Docs/BasicsImplementationStatus.md. Complete Demo/golden and Player rendering are separate validation scopes.
